## 项目简介

CabHive 是山东大学数据库课程设计作品，项目设计目标为企业级智能网约车管理平台，采用微服务架构设计，融合了人工智能算法、大数据分析和实时位置追踪等前沿技术。


## 系统架构与技术亮点

### 微服务架构设计
CabHive 采用模块化微服务架构，各功能模块独立部署、灵活扩展，包括：
- **智能算法模块**：基于深度学习的派单算法和风险检测系统
- **移动端应用**：基于Taro框架的跨平台微信小程序
- **后端服务**：基于Go语言的高性能API服务
- **管理后台**：基于React 18 + TypeScript的现代化管理界面

### 核心技术栈
- **后端**：Go 1.23 + Gin + PostgreSQL + Redis + GORM
- **前端**：React 18 + TypeScript + Vite + Ant Design + Tailwind CSS
- **移动端**：Taro + React Hooks + 微信小程序原生API
- **AI服务**：Python + Flask + OpenAI API
- **部署**：Docker + Docker Compose

### 性能与扩展性
- 支持100,000+并发用户在线
- 每秒处理50,000+订单创建请求
- 99.99%系统可用性保障
- 毫秒级API响应时间
- 支持水平扩展和容器化部署

## 功能模块介绍

### 1. 智能算法模块 (AI)
基于深度强化学习的智能调度算法，融合实时路况、历史大数据分析和司机画像，实现毫秒级订单响应和精准匹配。内置基于行为分析的智能风控引擎，采用孤立森林算法和深度神经网络构建多层异常检测模型。

[详细说明请查看 AI 模块 README](cab-hive-ride-management-ai/README.md)

### 2. 移动端应用 (App)
跨平台微信小程序，支持乘客和司机双端角色，提供完整的出行服务流程：
- 智能路线规划与实时导航
- 实时位置追踪与安全保障
- 双端角色管理与差异化功能体验
- 完整的订单生命周期管理
- 司机与车辆信息审核流程
- AI客服系统支持

[详细说明请查看 App 模块 README](cab-hive-ride-management-app/README.md)

### 3. 后端服务 (Backend)
高性能Go语言微服务，提供完整的企业级API支持：
- 用户认证与权限管理（JWT + 微信登录）
- 司机与车辆管理（注册、审核、封禁等）
- 订单管理系统（创建、跟踪、取消等）
- 支付系统集成（支付宝）
- AI客服系统（OpenAI API）
- 风险预警与监控（实时位置偏离检测、订单超时监控等）
- 图片上传与存储（阿里云OSS）

[详细说明请查看 Backend 模块 README](cab-hive-ride-management-backend/README.md)

### 4. 管理后台 (Web)
现代化管理界面，为平台运营人员提供全面的数据支持和业务管控能力：
- 用户、司机、车辆管理
- 订单监控与管理
- 反馈处理与跟踪
- 收入统计与分析
- 警报管理与实时监控
- 数据可视化展示

[详细说明请查看 Web 模块 README](cab-hive-ride-management-web/README.md)

## 使用与拓展说明

### 环境要求

在使用或拓展本课设项目之前，请确保您的开发环境满足以下要求：

1. **后端服务**：
   - Go 1.23 或更高版本
   - PostgreSQL 13+ 数据库
   - Redis 7.0+ 缓存服务
   - Docker 和 Docker Compose（推荐用于快速部署）

2. **前端管理后台**：
   - Node.js 18.x 或更高版本
   - npm 8.x 或 yarn 1.22.x

3. **移动端应用**：
   - 微信开发者工具
   - Node.js 16.x 或更高版本
   - npm 8.x 或 yarn 1.22.x

4. **AI智能算法模块**：
   - Python 3.7+
   - pip 包管理器
   - Docker 和 Docker Compose（推荐用于快速部署）

### 安装和部署步骤

1. **克隆项目**：
   ```bash
   git clone <repository-url>
   cd cab-hive-ride-management
   ```

2. **启动基础设施**：
   在开发阶段，可以使用项目根目录下的`docker-compose.yaml`文件快速启动数据库和Redis服务：
   ```bash
   # 启动数据库和Redis服务
   docker-compose up -d
   ```

3. **配置各模块**：
   - 根据各模块README文件中的说明，配置相应的环境变量和配置文件
   - 特别注意数据库连接信息、API密钥等敏感信息的配置

4. **启动各服务**：
   - 按照各模块README文件中的说明，分别启动AI模块、后端服务、前端管理和移动端应用
   - 建议按以下顺序启动：AI模块 → 后端服务 → 管理后台 → 移动端应用

### 扩展建议

本项目具有良好的模块化设计和扩展性，您可以考虑以下扩展方向：

1. **功能扩展**：
